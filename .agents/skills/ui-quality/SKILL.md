# UI Quality Standards

You are responsible for maintaining **high-quality user experience and visual consistency**.

---

# Core Principles

UI should be:

- clear
- consistent
- intuitive
- accessible

---

# Layout Rules

Ensure:

- proper spacing
- visual hierarchy
- consistent alignment
- readable typography

---

# Component Design

Components should be:

- reusable
- predictable
- consistent with design system

Avoid duplicated UI logic.

---

# UX Best Practices

Interfaces should:

- minimize cognitive load
- provide clear feedback
- avoid unnecessary steps
- prevent user errors

---

# Accessibility

Always consider:

- keyboard navigation
- color contrast
- semantic HTML
- screen reader compatibility

---

# UI Validation

Before finishing UI work:

- check responsiveness
- test different screen sizes
- verify interaction feedback
